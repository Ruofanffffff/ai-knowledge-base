## 核心功能

### 1. 重复检测模态框
**组件**: `DuplicateDetectionModal`

**功能特性**:
- 紫色主题，圆角设计，阴影效果
- 显示新文件和现有文件的对比信息
- 文件名、大小、上传时间对比
- 根据重复类型显示不同提示信息
- 三个操作按钮：覆盖/保存为新文件/取消
- Framer Motion 动画（淡入淡出、缩放）
- 键盘快捷键支持（Esc 取消、Enter 保存为新文件）
- 点击背景关闭模态框

**UI 设计**:

### 2. API 集成

**新增方法**: `apiService.resolveDuplicate()`

```typescript
async resolveDuplicate(
  action: 'replace' | 'keep-both' | 'cancel',
  tempFileId: string,
  existingFileId?: string
): Promise<ApiResponse<Document>>
```

**更新方法**: `apiService.uploadDocument()`
- 现在返回 `ApiResponse<Document | any>` 以支持重复检测响应
- 添加 `isDuplicate` 标志识别重复文件

### 3. 上传流程集成

**新增状态**:
- `checking-duplicate` - 检查重复中
- 错误消息显示
- 速度和预计时间（接口已准备，待实现）

**流程**:
1. 用户选择文件
2. 开始上传（status: uploading）
3. 后端检测到重复 → 显示模态框（status: checking-duplicate）
4. 用户选择操作：
   - 覆盖 → 调用 resolveDuplicate('replace')
   - 保存为新文件 → 调用 resolveDuplicate('keep-both')
   - 取消 → 清理临时文件
5. 处理完成（status: processing → done）
6. 刷新文档列表

### 4. 错误处理

**错误类型**:
- 网络错误：显示"网络错误，请重试"
- 上传失败：显示后端返回的错误消息
- 处理失败：显示"处理失败"

**错误显示**:
- 在上传进度面板显示错误消息
- 进度条变红色
- 显示错误图标
