## 技术亮点

### 1. 智能降级策略

系统具有完善的错误处理和降级机制：
- LLM失败 → 自动回退到算法提取
- 算法失败 → 使用LLM提取
- 网络超时 → 自动重试（最多3次）
- 格式错误 → 使用默认值

### 2. 性能优化

- **缓存机制**：避免重复LLM调用，节省成本
- **批处理支持**：提高大量文档处理效率
- **超时控制**：防止长时间阻塞
- **Token追踪**：实时监控成本

### 3. 多语言支持

- 支持中文文档提取
- 支持英文文档提取
- 自动语言检测
- 保留原始语言

### 4. 质量保证

- 自动验证提取结果
- 计算质量指标
- 生成验证报告
- 警告信息提示

### 处理时间

- **算法提取**：~100ms
- **LLM提取**：~3-5s（首次），~100ms（缓存命中）

基于测试文档"摄影课.md"：
