I will fix the "Network Error" on the Android app by allowing cleartext traffic, which is required when the app connects to a local HTTP server (not HTTPS).

### **1. Configure Android Network Security**
- **Create `network_security_config.xml`**:
  - I will create a new file at `android/app/src/main/res/xml/network_security_config.xml`.
  - This configuration will explicitly allow cleartext traffic (HTTP) for all domains, or specifically for the local server IP. This is crucial for development environments where SSL is not set up.

- **Update `AndroidManifest.xml`**:
  - I will modify `android/app/src/main/AndroidManifest.xml` to reference the new network security configuration using `android:networkSecurityConfig="@xml/network_security_config"`.
  - I will also ensure `android:usesCleartextTraffic="true"` is set in the `<application>` tag as a fallback.

### **2. Update Capacitor Configuration**
- **Allow Cleartext in Capacitor**:
  - I will check `capacitor.config.json` to ensure `server.cleartext` is set to `true`. This tells Capacitor to allow loading content from HTTP sources.

### **3. Verification (User Action Required)**
- After I apply these changes, you will need to rebuild and reinstall the Android app (`npx cap sync` followed by running in Android Studio) for the changes to take effect.
- You should then be able to log in without the "Network Error".

### **Why this is happening**:
By default, modern Android versions (Android 9/Pie and above) block all cleartext (HTTP) traffic to protect user data. Since your local development server runs on `http://` (not `https://`), the app blocks the connection, resulting in a generic "Network Error". My plan explicitly permits this traffic for your app.
