To fix the issue where the chat window doesn't automatically scroll to the bottom as new content is generated, I need to implement an auto-scroll mechanism in `client/src/pages/AISearch.tsx`.

**Current Issue:**
The chat content is updated in real-time (via streaming), but the container (`div` with `overflow-y-auto`) stays at its current scroll position. This forces the user to manually scroll down to see the latest generated text.

**Solution:**
1.  **Create a Ref**: Create a `useRef` pointing to the end of the message list (or the message container itself).
2.  **Trigger Scroll**: Use a `useEffect` hook that triggers whenever the `messages` array changes (or specifically when content is streaming).
3.  **Scroll Logic**: Inside the effect, call `scrollIntoView({ behavior: 'smooth' })` on the ref element to ensure the view stays at the bottom.

**Implementation Plan:**

1.  **Update `client/src/pages/AISearch.tsx`**:
    *   Import `useRef` from 'react'.
    *   Create `const messagesEndRef = useRef<HTMLDivElement>(null);`.
    *   Add a `<div ref={messagesEndRef} />` at the end of the message list (inside the scrollable container).
    *   Add a `useEffect` that depends on `[messages]` (or `[messages, isSearching]`) to trigger the scroll.

```tsx
  // ... imports
  import { useRef } from 'react';

  // ... inside component
  const messagesEndRef = useRef<HTMLDivElement>(null);

  const scrollToBottom = () => {
    messagesEndRef.current?.scrollIntoView({ behavior: "smooth" });
  };

  useEffect(() => {
    scrollToBottom();
  }, [messages]); // Scroll whenever messages change (including streaming updates)

  // ... inside render
  <div className="flex-1 overflow-y-auto ...">
    {messages.map(...)}
    {isSearching && (...)}
    <div ref={messagesEndRef} /> {/* Anchor for scrolling */}
  </div>
```

This ensures that every time a new token is received (updating the `messages` state), the view will scroll to the bottom. I will implement this now.
