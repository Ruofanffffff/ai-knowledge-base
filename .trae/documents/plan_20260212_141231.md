I have designed a comprehensive plan to upgrade Hi Brain to an **Agentic RAG (Retrieval-Augmented Generation)** architecture. This will significantly improve its ability to find relevant information (like the "AI内涝" document) by understanding meaning rather than just matching keywords.

### 🏗️ Architecture: Agentic RAG

We will move from a linear `Search -> Answer` flow to a dynamic **ReAct (Reason + Act)** loop.

#### 1. Core Components
*   **The Brain (Agent)**: An autonomous loop that analyzes the user's request, decides which tools to use, executes them, and evaluates the results before answering.
*   **The Memory (Semantic Search)**: Instead of just keywords, we will use **Vector Embeddings**. This allows the system to understand that "waterlogging" is related to "flooding" or "inundation", even if the exact words differ.
*   **The Hands (Tools)**:
    *   `KnowledgeBaseTool`: Performs Hybrid Search (Semantic Vector Search + Keyword Search).
    *   `WebSearchTool`: Searches the internet for real-time info.

#### 2. Detailed Implementation Plan

**Step 1: Semantic Indexing Infrastructure**
*   **Database Upgrade**: Add an `embedding` column to the SQLite `documents` table to store vector data.
*   **Embedding Service**: Implement a `getEmbedding(text)` function using the **Qwen text-embedding-v3** API (since you already use Qwen).
*   **Backfill Script**: Create a utility to generate embeddings for all your existing documents (including "AI内涝") so they become semantically searchable immediately.
*   **Auto-Indexing**: Update the file upload API (`POST /api/documents`) to automatically generate embeddings for new files.

**Step 2: The Agent Core (Server-Side)**
*   **Agent Class**: Create a robust `Agent` class in `server.js`.
*   **Tool Definitions**: Define clear interfaces for `search_knowledge_base` and `search_web`.
*   **ReAct Loop**: Implement the logic:
    1.  **Thought**: "User is asking about AI waterlogging. I should check the knowledge base first."
    2.  **Action**: Call `search_knowledge_base("AI waterlogging")`.
    3.  **Observation**: (Receives content from the "AI内涝" document).
    4.  **Final Answer**: Synthesize the information for the user.

**Step 3: Search Logic Upgrade (Hybrid Search)**
*   Implement a **Cosine Similarity** algorithm in Node.js (efficient enough for personal knowledge bases < 10,000 docs).
*   Combine vector results with the existing keyword results to ensure we catch both conceptual matches and exact phrase matches.
