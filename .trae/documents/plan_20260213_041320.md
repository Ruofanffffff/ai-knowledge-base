I will fix the chat history sync and mobile message processing issues in the Hi Brain feature.

### **1. Synchronize Chat History Across Devices**
- **Current State**: Chat history is stored in `localStorage`, which is device-specific. This is why mobile and web histories are out of sync.
- **Solution**:
  - Implement **backend API endpoints** to store and retrieve chat sessions and messages (`GET /api/user/chats`, `POST /api/user/chats`, etc.).
  - Update `AISearch.tsx` to fetch history from the server on mount, instead of `localStorage`.
  - Update `handleSend` to save new messages to the server after generation.
  - *Note*: For this iteration, I will implement a basic file-based persistence on the server (similar to how documents are stored) to enable syncing without setting up a complex new database schema, ensuring quick turnaround.

### **2. Fix Mobile Message Sending Issue**
- **Current State**: The user reports that on mobile, only "thinking" bubbles appear with no response.
- **Diagnosis**:
  - The `fetch` call in `handleSend` uses a relative URL (`/api/ai/search`).
  - On the Android app (Capacitor), requests to relative URLs might not be resolving correctly to the backend server IP (192.168.x.x), despite the global base URL configuration, or the stream reading logic is failing in the WebView environment.
  - It's also possible that the SSE (Server-Sent Events) stream is being buffered or blocked by the mobile network layer/WebView.
- **Solution**:
  - Ensure the API call uses the fully qualified URL from the environment config (`import.meta.env.VITE_API_BASE_URL`).
  - Add error handling specifically for the fetch stream reader to detect if it's failing silently on mobile.
  - Verify that the Android network security config allows the connection (already done previously, but double-check).

2.  **Frontend (`AISearch.tsx`)**:
    - Replace `localStorage` logic with API calls.
    - Update `handleSend` to use the full API URL.
    - Add better error logging for mobile debugging.
3.  **Build**: Rebuild frontend and sync Capacitor.
