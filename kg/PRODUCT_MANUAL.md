# Schema 驱动知识图谱系统 - 产品使用手册

## 1. 产品概述

### 1.1 什么是 Schema 驱动知识图谱?

Schema 驱动知识图谱是一个智能的个人知识库系统,能够自动从文档中提取知识,构建结构化的知识图谱。系统采用 Schema 驱动的方式,通过 250 个预定义的知识模板,自动识别和组织文档中的信息。

### 1.2 核心特性

- **智能文档解析**: 支持 Word、PDF、Excel 等多种格式
- **自动知识抽取**: 从文档中自动提取实体、关系和属性
- **Schema 驱动**: 250 个预定义模板,覆盖工作、科研、生活等多个领域
- **可视化展示**: 直观的知识图谱可视化界面
- **高效搜索**: 基于知识图谱的智能搜索
- **低成本**: 90% Token 节省,降低 AI 调用成本

### 1.3 适用场景

- **科研工作**: 实验记录、数据分析、文献管理
- **政府工作**: 政策文档、会议记录、公文管理
- **个人生活**: 日记、健康记录、目标追踪
- **旅行摄影**: 旅行日志、照片管理、拍摄记录
- **学习笔记**: 读书笔记、课程笔记、知识整理

## 2. 快速开始

### 2.1 访问系统

打开浏览器,访问: http://localhost:5173/

### 2.2 登录系统

**默认管理员账号**:
- 用户名: `admin`
- 密码: `admin123`

⚠️ **重要**: 首次登录后请立即修改密码!

### 2.3 修改密码

1. 点击右上角用户头像
2. 选择"设置"
3. 在"安全设置"中修改密码
4. 输入旧密码和新密码
5. 点击"保存"

## 3. 文档管理

### 3.1 上传文档

1. 点击左侧菜单"文档管理"
2. 点击"上传文档"按钮
3. 选择文件 (支持 Word、PDF、Excel)
4. 填写文档标题和描述
5. 选择分类和标签
6. 点击"上传"

**支持的文件格式**:
- Word: `.docx`
- PDF: `.pdf`
- Excel: `.xlsx`

**文件大小限制**: 最大 100MB

### 3.2 查看文档

1. 在文档列表中点击文档标题
2. 查看文档详情、内容和元数据
3. 查看自动生成的标签和分类
4. 查看关联的知识图谱

### 3.3 编辑文档

1. 在文档详情页点击"编辑"按钮
2. 修改标题、描述、分类或标签
3. 点击"保存"

### 3.4 删除文档

1. 在文档列表中选择要删除的文档
2. 点击"删除"按钮
3. 确认删除操作

⚠️ **注意**: 删除文档会同时删除相关的知识图谱数据!

## 4. 知识图谱

### 4.1 查看知识图谱

1. 点击左侧菜单"知识图谱"
2. 系统自动展示知识图谱可视化
3. 使用鼠标拖拽和缩放查看图谱

### 4.2 图谱交互

**节点操作**:
- **点击节点**: 查看实体详情
- **拖拽节点**: 调整节点位置
- **双击节点**: 展开相关节点

**边操作**:
- **点击边**: 查看关系详情
- **悬停边**: 显示关系类型和权重

**视图控制**:
- **鼠标滚轮**: 缩放视图
- **拖拽空白**: 平移视图
- **双击空白**: 重置视图

### 4.3 筛选和搜索

**按实体类型筛选**:
1. 点击右侧"筛选"面板
2. 选择实体类型 (事件、地点、观测等)
3. 图谱自动更新显示

**按置信度筛选**:
1. 在筛选面板中调整置信度滑块
2. 只显示高置信度的实体和关系

**搜索实体**:
1. 在搜索框中输入关键词
2. 系统高亮匹配的节点
3. 点击搜索结果跳转到节点

### 4.4 实体详情

点击实体节点后,右侧面板显示:

- **基本信息**: 实体名称、类型、置信度
- **属性**: 实体的所有属性和值
- **来源**: 支撑该实体的文档和段落
- **关系**: 与其他实体的关系
- **Schema**: 匹配的 Schema 模板

**操作**:
- **查看来源**: 点击来源链接跳转到原文档
- **查看关系**: 点击关系查看详情
- **导出实体**: 导出实体数据为 JSON

### 4.5 关系详情

点击关系边后,右侧面板显示:

- **关系类型**: 内建关系、共现关系或语义关系
- **源实体**: 关系的起点
- **目标实体**: 关系的终点
- **权重/置信度**: 关系的强度
- **证据**: 支撑该关系的文档段落

## 5. Schema 管理

### 5.1 查看 Schema

1. 点击左侧菜单"Schema 管理"
2. 查看所有 250 个预定义 Schema
3. 按场景分类浏览 (科研、政府、生活等)

### 5.2 Schema 详情

点击 Schema 名称查看:

- **Schema 名称**: 如"EITV"、"地下水位变化事件"
- **适用场景**: 科研/政府、个人生活、旅行等
- **核心字段**: 触发该 Schema 所需的字段
- **示例描述**: 如何使用该 Schema 的示例
- **实体类型**: 该 Schema 生成的实体类型
- **内建关系**: Schema 定义的关系模板

### 5.3 Schema 筛选

**按场景筛选**:
- 科研/政府 (100 个)
- 个人生活 (50 个)
- 旅行/休闲 (40 个)
- 摄影/后期 (60 个)

**按实体类型筛选**:
- 事件实体 (EventEntity)
- 地点实体 (LocationEntity)
- 观测实体 (ObservationEntity)
- 旅行实体 (TravelEntity)
- 摄影实体 (PhotographyEntity)

### 5.4 启用/禁用 Schema

1. 在 Schema 列表中找到目标 Schema
2. 点击"启用"或"禁用"按钮
3. 禁用的 Schema 不参与知识抽取

⚠️ **注意**: 禁用 Schema 不会删除已生成的实体!

## 6. 统计和分析

### 6.1 系统统计

点击左侧菜单"统计"查看:

- **文档统计**: 文档总数、分类分布
- **实体统计**: 实体总数、类型分布、置信度分布
- **关系统计**: 关系总数、类型分布
- **Schema 统计**: 活跃 Schema 数量、匹配率

### 6.2 Token 使用统计

查看 LLM Token 使用情况:

- **每日使用量**: 当前日期的 Token 消耗
- **每日限额**: 配置的每日 Token 限额
- **使用率**: 当前使用量占限额的百分比
- **预警状态**: 是否接近或超过限额

**优化建议**:
- 当使用率 > 80% 时,系统会提供优化建议
- 可以调整 LLM 调用频率降低成本
- 启用缓存提高效率

### 6.3 质量统计

查看知识图谱质量指标:

- **平均实体置信度**: 所有实体的平均置信度
- **平均关系置信度**: 所有关系的平均置信度
- **低质量实体数**: 置信度 < 0.6 的实体数量
- **低质量关系数**: 置信度 < 0.5 的关系数量

## 8. 使用技巧

### 8.1 提高知识抽取质量

**文档准备**:
- 使用结构化的文档格式
- 保持文档内容清晰、完整
- 避免过多的图片和表格混排

**标题和段落**:
- 使用清晰的标题层级
- 每个段落表达一个完整的意思
- 避免过长的段落

**关键信息**:
- 明确标注时间、地点、数值等关键信息
- 使用标准的单位和格式
- 避免使用缩写和俚语

### 8.2 优化 Token 使用

**启用缓存**:
- 系统自动缓存 LLM 响应
- 相似查询会复用缓存结果
- 缓存有效期 24 小时

**调整调用频率**:
- 在"设置"中调整 LLM 调用频率
- 降低频率可以减少 Token 消耗
- 但可能影响知识抽取质量

**使用规则优先**:
- 系统优先使用规则和算法
- 只在必要时调用 LLM
- 90% 的场景不需要 LLM

### 8.3 提高搜索效率

**使用精确搜索**:
- 输入完整的实体名称
- 使用引号进行精确匹配
- 例如: `"2025年北京水位变化"`

**使用筛选条件**:
- 先筛选实体类型
- 再筛选置信度范围
- 最后进行关键词搜索

**使用图遍历**:
- 从一个实体出发
- 查看相关的实体和关系
- 逐步探索知识图谱

## 9. 常见问题

### 9.1 文档上传失败

**问题**: 上传文档时提示失败

**解决方案**:
1. 检查文件格式是否支持
2. 检查文件大小是否超过限制
3. 检查文件是否损坏
4. 尝试重新上传

### 9.2 知识图谱为空

**问题**: 上传文档后知识图谱为空

**解决方案**:
1. 检查文档内容是否包含结构化信息
2. 检查 Schema 是否启用
3. 查看系统日志了解详情
4. 尝试重建知识图谱

### 9.3 实体置信度低

**问题**: 生成的实体置信度很低

**解决方案**:
1. 检查文档来源 (OCR/ASR 会降低置信度)
2. 提高文档质量
3. 使用更清晰的表达
4. 增加支撑该实体的文档数量

### 9.4 Token 超限

**问题**: 系统提示 Token 使用超限

**解决方案**:
1. 查看 Token 使用统计
2. 降低 LLM 调用频率
3. 启用缓存
4. 增加每日 Token 限额

### 9.5 搜索结果不准确

**问题**: 搜索结果与预期不符

**解决方案**:
1. 使用更精确的关键词
2. 使用筛选条件缩小范围
3. 检查实体名称是否正确
4. 尝试使用同义词搜索
